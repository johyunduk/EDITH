# EDITH 사용 설명서

설치·실행은 [README](../README.md) 의 「빠른 시작」. 여기서는 화면을 어떻게 쓰는지 순서대로 설명합니다. 고쳐 쓰는 법은 [customize.md](customize.md).

## 처음 켜면

`edith` 를 치면 브라우저가 열립니다. herdr 가 비어 있으면 왼쪽에 「+ 새 워크스페이스」 만 보입니다.

1. **「+ 새 워크스페이스」** — 이름과 시작 폴더를 넣습니다. 폴더 칸은 셸처럼 하위 폴더를 추천하고, Tab 이면 첫 추천을 넣습니다.
2. 만들어진 셸 pane 이 열립니다. 아래 칸에 명령을 치거나, 「대기 중」 줄의 **Claude**·**Codex** 버튼으로 그 자리에 에이전트를 띄웁니다.
3. 에이전트에게 입력칸으로 일을 시키면, 대화가 위에 쌓이고 왼쪽 목록에 상태가 보입니다.

터미널 herdr(`herdr`)로 같은 서버에 붙어도 됩니다 — 어느 쪽에서 바꿔도 양쪽에 보입니다.

## 화면 구성

**머리줄**

- 맨 왼쪽 버튼(또는 ⌘B·Ctrl+B) — 왼쪽 목록 접기·펴기.
- **herdr**·**스킬**·**공방**·**런**·**설정** — 화면을 오갑니다. 설정에서 테마와 커밋 지킴이를 바꿉니다(아래 「설정」).
- **알림 켜기**(종 옆, 허락 전에만) — 한 번 눌러 브라우저 알림을 허락하면, 어느 pane 이든 승인 대기가 될 때 알림과 짧은 소리가 납니다. 탭 제목에도 `(2) EDITH` 처럼 수가 붙습니다.
- **LOCAL·REMOTE** — 이 기기의 EDITH 면 LOCAL, 다른 기기의 EDITH 를 터널로 열었으면 보라색 REMOTE.
- **종** — 알림함. 승인 대기·끝남이 된 순간이 쌓입니다(이 브라우저에 최근 100개). 누르면 그 pane 으로 갑니다. 「확인 필요」 는 그 pane 이 아직 그 상태인 것.

**왼쪽 목록(herdr 트리)**

- 워크스페이스 → 탭 → pane. 레포의 링크 워크트리는 그 레포 밑에 묶입니다. 작업 중이거나 승인 대기인 워크스페이스는 저절로 펼쳐집니다.
- 점 색 — 하늘색 작업 중, 주황 승인 대기, 초록 끝남. 아이콘 — Claude·Codex·셸.
- **끌어 놓기** — pane 을 다른 워크스페이스 위에 놓으면 그 워크스페이스의 새 탭으로, 워크스페이스를 다른 워크스페이스 위에 놓으면 그 앞으로.
- **원격 화면** — 다른 기기의 EDITH 를 터널로 열면 화면 둘레가 보라색이고 머리줄 오른쪽에 보라색 **REMOTE**(이 기기 화면은 회색 **LOCAL** — 기기 이름은 마우스를 올리면), 탭 제목에 `[그 기기]` 가 붙습니다. 거기서 하는 일은 그 기기에서 돕니다. 원격 화면에는 「다른 기기」 칸이 없습니다.
- **맨 아래 — 다른 기기.** 이어 둔 기기(예: 회사)를 누르면 SSH 터널로 그 기기의 EDITH 가 새 탭에 열립니다. **+ 다른 기기 잇기** 로 Tailscale 기기를 고르고 그 기기 사용자 이름·비밀번호를 넣으면 SSH 키를 등록하고 목록에 더합니다(그 기기의 Remote Login 이 켜져 있어야 — README 「다른 기기의 EDITH 열기」).
- **우클릭** — pane: 나누기(왼·오·위·아래), 새 탭으로 빼기, 여기서 Claude·Codex 띄우기(쉬는 셸), Esc·Ctrl+C 보내기, 경로 복사, 닫기(두 번 눌러야). 워크스페이스: 새 탭, 이름 바꾸기, 맨 위·아래로, 경로 복사. Shift+우클릭은 브라우저 기본 메뉴.

## pane 화면

**첫째 줄** — 워크스페이스 이름, 브랜치(누르면 이름 복사 — 링크 워크트리면 원본 레포 브랜치도), 상태, 그리고 오른쪽 버튼들:

- **백그라운드 작업** — Claude 가 백그라운드로 띄운 셸·에이전트가 돌고 있을 때만 보입니다. 누르면 목록, 작업을 누르면 출력 끝. 줄 오른쪽 **끄기** 는 바로 죽이지 않고 그 Claude 에게 꺼도 되는지 묻습니다 — 필요 없으면 Claude 가 TaskStop 으로 끄고, 아직 필요하면 이유를 답합니다(일하는 중이면 그 일이 끝난 뒤에).
- **원격** — Claude pane 의 Remote Control. 켜져 있으면(초록 점) 누르면 claude.ai 에서 그 세션이 열려 다른 기기·폰에서 이어 씁니다. 꺼져 있으면 **원격 켜기**(`/remote-control` 을 보냅니다, 일하는 중에는 끝난 뒤에).
- **변경** — 이 pane 폴더의 git 변경(아래 「변경 보기」).
- **원래 화면** — 대화·기록 대신 터미널 화면 그대로.
- **← → ↑ ↓** — 그쪽에 새 칸(같은 폴더). **×** — 칸 닫기(한 번 더 눌러야).

**둘째 줄** — pane 이름·id, 사용량(모델·effort·컨텍스트 %·5시간·7일 한도 — 50% 넘으면 주황, 80% 넘으면 빨강), 작업 폴더(옆 버튼으로 복사), 탭에 칸이 여럿이면 **탭 전체 N칸 / 이 pane 만**.

**본문**

- **에이전트 pane — 대화.** 세션 기록을 말·내 입력·도구 호출로 풀어 보여 줍니다. 도구 줄을 누르면 결과. 맨 위로 올리거나 **이전 대화 더 보기** 로 앞을 이어 받고, 멀리 올라가 있으면 **맨 아래로** 가 뜹니다. 작업 중에는 아직 기록에 없는 진행 부분(쓰는 중인 글·스피너)이 맨 아래에 붙습니다.
- **셸 pane — 기록.** 지난 출력을 「명령 + 출력」 카드로 나눕니다. 긴 출력은 끝 40줄, 누르면 전부. vim·less·top·`git log` 처럼 화면 전체를 쓰는 프로그램이 돌면 저절로 터미널로 바뀝니다.
- **터미널.** 실시간 화면입니다. 누르면 **입력 모드**(파란 테두리)가 되어 키·휠이 그 pane 으로 갑니다. 다른 화면이 입력 중이면 **입력 가져오기**. **보기로** 로 빠집니다. 승인 메뉴용 빠른 키(1·2·3·↑·↓·Enter·Esc·Ctrl+C)는 입력 모드 없이 갑니다.

**탭 전체 보기** — herdr 배치 그대로 칸을 놓습니다. 칸 어디를 눌러도 그 pane 이 입력칸의 대상이 되고, 칸 경계를 끌면 크기가, 칸 머리를 다른 칸 가장자리에 놓으면 그쪽에 붙고 가운데에 놓으면 자리를 바꿉니다.

## 입력칸

- **Enter** 보내기, **Shift+Enter** 줄바꿈. 한글 조합 중 Enter 는 보내지 않습니다.
- **쓰다 만 글** — pane 마다 따로 이 브라우저에 남습니다. 다른 pane 에 갔다 와도, 새로 고치거나 탭을 닫았다 열어도 그 pane 에 쓰던 글이 그대로 있습니다. 보내면 지워집니다.
- **자동 완성** — 맨 앞 `/` 는 명령·스킬, 어디서든 `@` 는 파일. ↑↓ 로 고르고 Tab·Enter 로 넣고 Esc 로 닫습니다. Codex pane 에는 `/스킬` 을 `$스킬` 로 바꿔 보냅니다.
- **📎 첨부** — 파일을 골라 올리면 경로가 입력칸에 들어갑니다. 스크린샷은 클립보드로 찍어 입력칸에 붙여넣으면 같은 방식으로 올라갑니다.
- **📸 스크린샷**(macOS, 이 기기 화면에서만) — ⌘⇧4 처럼 영역을 골라 찍으면(스페이스: 창, Esc: 취소) 첨부 폴더에 두고 경로를 넣습니다. 원격으로 보는 화면에서는 그 기기 화면이 찍히므로 버튼이 없습니다 — 그때는 클립보드로 찍어 붙여넣습니다.
- **중지** — 에이전트는 Esc(하던 일 멈추기), 셸은 Ctrl+C(돌고 있는 명령 끝내기).
- **질문·승인** — 에이전트가 답을 기다리면 입력칸 자리에 질문과 선택지 버튼이 뜹니다. 누르면 그 번호로 답합니다. 번호 없이 ❯ 로 고르는 메뉴(폴더 신뢰 등)는 그 줄까지 옮겨 Enter 를 보냅니다. Codex 폴더 신뢰처럼 번호로 고르기만 되는 화면은 Enter 까지 보내 확정합니다. 여러 개 고르기는 누를 때마다 체크가 켜지고 꺼지며, **다음 →** 으로 다음 질문·제출 화면(**Submit answers**)으로 넘어갑니다. 「직접 입력」 선택지는 고른 뒤 입력칸에 쓴 글이 답이 됩니다. 미리 보기가 달린 Claude 질문은 선택지 옆(좁은 화면에선 아래)에 지금 커서가 있는 선택지의 미리 보기를 보여 줍니다. **↑ ↓** 로 커서를 옮기면 다른 선택지 것이 보입니다(고르지는 않습니다). 이 꼴에서는 Claude 가 선택지 설명을 화면에 그리지 않아 설명 줄이 없습니다. 승인 화면(Claude 의 명령 실행·파일 쓰기·고치기·웹 가져오기)은 종류(「Bash command」 등)를 위에 작게, 설명을 굵게 두고, 명령·파일 내용·diff 를 터미널 색 그대로 따로 보여 줍니다. Codex 승인은 실행할 명령(`$ …`)을 고정폭으로 보여 줍니다. 답을 기다리는 동안 입력칸에 쓴 글은 보내지 않고 선택지를 먼저 고르라고 알립니다.

## 변경 보기

pane 머리의 **변경**.

- **커밋 안 한 것 / 브랜치 전체 / 커밋별** — 브랜치 전체는 기준 브랜치(origin 의 dev·develop·master·main 중 있는 것)에서 갈라진 뒤의 변경.
- 왼쪽 파일 목록, 오른쪽 파일 카드. **한 줄 / 나란히**, **모두 접기·펼치기**. lock·빌드 산출물·아주 큰 파일은 처음에 접혀 있습니다.
- 파일마다 **봤음** 표시 — 그 파일 변경이 그대로인 동안만 남습니다.
- **AI 요약** — 파일마다 무엇을 왜 바꿨는지 Claude(haiku)에 한두 줄로 묻습니다(누를 때만, 한 번 물은 것은 기억).

## 스킬

Claude·Codex 의 스킬·명령 목록. 범위(**내 것·공유 / 플러그인 / Codex 기본 / 전체**)와 찾기로 좁히고, 처음 화면은 서로 부르는 관계도입니다. 스킬을 누르면 설명, 부르는 곳·부르는 것 그림, 스킬 폴더의 md 본문.

**옮기기 — 내보내기·가져오기**(왼쪽 위). 다른 기기의 스킬을 이 기기로 옮길 때 씁니다. 사이드 메뉴 아래에서 그 기기의 EDITH 를 열어 거기서 내려받고, 이 기기 EDITH 에서 가져옵니다.

- **내려받기** — 다른 기기의 EDITH 를 터널로 열어 볼 때만 됩니다(이 기기 화면에서는 꺼져 있습니다 — 이미 여기 있는 것이라). 내 것·공유 스킬, Claude 명령, Codex 프롬프트를 골라 `edith-skills-<날짜>.json.gz` 하나로 내려받습니다. 공유 스킬(`~/.agents/skills` 와 그걸 가리키는 `~/.claude/skills` 링크)은 링크째 담습니다.
  - **공개 스킬**(`npx skills add` 로 깐 것 — 목록에 「공개 · owner/repo」)은 파일 대신 설치 명령으로 담습니다.
  - 고른 스킬이 부르는 **플러그인**(예: diagram-design)은 설치 명령으로 같이 담고, 누가 부르는지 보여 줍니다. 부르지 않는 켜 둔 플러그인은 고를 때만.
  - 고른 스킬이 부르는 내 스킬을 빠뜨리면 「빠진 것」 으로 알려 주고 **같이 넣기** 로 더합니다.
- **가져오기** — 그 파일을 고르면 무엇이 들어오는지 먼저 보여 줍니다. 새로 들어오는 것은 넣고, 이미 있는 것은 **덮어쓰기** 를 고른 것만 바꿉니다. 「설치로 받는 것」 에서 고른 공개 스킬·플러그인은 EDITH 가 설치합니다(`npx skills add … -g -a claude-code -a codex`, `claude plugin marketplace add` → `claude plugin install`). 이미 깐 것은 「이미 있음」. Claude·Codex 는 새 세션부터 봅니다.
- 묶음 안의 경로는 `~/.claude/skills`·`~/.claude/commands`·`~/.agents/skills`·`~/.codex/skills`·`~/.codex/prompts` 아래만 받습니다(밖을 가리키면 통째로 거절).

## 공방

체인과 엔진을 그리는 곳. 말은 넷입니다.

- **노드** — 일 하나. 스킬 · 명령을 씁니다(엔진에서는 체인 · 엔진도).
- **체인** — 노드를 화살표로 이은 것(예: 「기획 파악」).
- **엔진** — 체인을 이은 것(예: 「기능 개발」 = 기획 파악 → 구현 계획 → … → 테스트). 엔진도 이을 수 있고(「개발」 엔진 → 「검증」 엔진), 스킬 · 명령 노드도 섞어 넣습니다.
- **런** — 체인이나 엔진을 한 번 돌린 것(아래 「런」).

체인 · 엔진 하나가 `~/.local/share/edith/workshop/<폴더>/` 하나입니다 — `engine.json`(노드 · 화살표 · 위치, 둘 다 같은 파일 꼴 — `kind` 로 가른다)과 `skills/<이름>/SKILL.md`(노드가 쓰는 스킬). 왼쪽 목록은 트리입니다 — 맨 위에는 다른 체인 · 엔진이 쓰지 않는 것(엔진 먼저)만 있고, 화살표로 펼치면 그 안에서 부르는 체인 · 엔진이 노드 순서대로 나옵니다(여러 곳에서 쓰면 부모마다). 초안이 있으면 초안의 이름 · 짜임으로 보이고(적용하면 그대로 된다) 이름 옆에 주황 점이 붙습니다. 펼친 상태는 이 브라우저에 기억하고, 고른 것이 접힌 곳에 있으면 거기까지 펼칩니다. 엔진은 겹친 판, 체인은 사슬 모양이고, 종류 · 폴더 이름 · 쓰는 곳은 이름에 마우스를 올리면 보입니다. 위의 「체인 | 엔진」 에서 「체인」 을 누르면 체인만 이름 순으로 한 번씩, 「엔진」 을 누르면 이 트리가 보입니다. 공방은 설계만 합니다 — 돌리는 것은 「런」.

- **새 체인 · 새 엔진**(왼쪽 위) — 이름(한글 가능)과 폴더 이름(영문 소문자 · 숫자 · -). 종류는 여기서 정하고 바뀌지 않습니다 — 체인은 스킬 · 명령 노드만, 엔진은 체인 · 엔진도 넣습니다. 체인에 다른 체인을 넣고 싶으면 엔진을 하나 만들어 둘을 거기에 넣습니다.
- **체인 지우기 · 엔진 지우기**(설정 줄 오른쪽) — 두 번 눌러 지웁니다. 폴더는 `~/.local/share/edith/workshop-trash/<폴더>-<시각>` 로 옮겨 두니 공방 폴더로 다시 옮기면 되살아납니다. 다른 엔진이 노드로 쓰고 있으면 지우지 않습니다. 지난 런은 자기 사본이 있어 그대로 남습니다.
- **캔버스** — 「+ 노드」 로 놓고, 노드 오른쪽 점을 끌어 다른 노드에 놓으면 이어집니다. 끌어 옮기기, 확대 · 축소, 미니맵. 명령 노드는 「$ 제목」 작은 칩으로 보입니다(명령은 올려 보거나 눌러서). 노드나 화살표를 고르고 Delete 로 지웁니다. 바꾼 것은 바로 `engine.json` 에 저장됩니다.
- **노드 칸**(노드를 누르면 왼쪽 아래) — 제목과 종류. 종류 탭(스킬 · 명령 · 체인 · 엔진)은 보기만 바꿉니다 — 그 탭에서 새 값을 실제로 고르거나 적어야 노드가 바뀌고 다른 연결이 빠집니다(탭을 눌러 보는 것만으로는 지워지지 않습니다).
  - **스킬** — 이 폴더의 스킬이나 설치된 Claude 스킬. 런에서 Claude 가 그 스킬대로 일합니다.
  - **명령** — 명령 한 줄(예: `pytest -q`, `$EDITH_ENGINE/test.sh`). 런에서 작업 폴더의 셸로 돌고, 끝 코드 0 이면 통과. 이 폴더 사본은 `$EDITH_ENGINE`, 작업 문서는 `$EDITH_WORK`, 런 입력은 `$EDITH_INPUT`.
    - **끝 코드 77** 이면 이 노드가 든 체인 · 엔진의 남은 노드를 「건너뜀」 으로 넘기고 그 뒤로 갑니다(예: 이번 일에 없는 쪽을 통째로 건너뛰기 — `[ -f "$EDITH_WORK/be/skip" ] && exit 77`). 맨 위 엔진에 놓인 명령이면 런의 남은 노드 전부.
    - **되돌리기** — `$EDITH_REWIND` 파일에 `{"to": "<노드 키>", "reason": "<이유>"}` 를 쓰고 끝 코드 0 으로 끝나면, 그 노드와 화살표로 뒤에 이어진 노드를 처음으로 돌려 거기서부터 다시 돕니다(작업 문서는 그대로). 노드 키는 돌리는 맨 바깥 엔진부터의 노드 id 를 `.` 로 이은 것(`n2.n3` — 체인 · 엔진 노드를 가리키면 그 안의 첫 노드부터)이고 런 화면 노드 상세에 보입니다. 몇 번까지 되돌릴지는 명령 쪽이 셉니다(지난 되돌림은 `$EDITH_RUN/run.json` 의 `rewinds`). 스킬 노드는 결과 파일 옆(같은 시도 폴더)에 같은 꼴의 `rewind.json` 을 결과 파일보다 먼저 쓰고 「통과」 로 끝내면 됩니다.
    - **갈래** 노드에는 갈래 이름이 `$EDITH_LANE` 으로 갑니다(본 줄이면 빈 글).
  - **체인 · 엔진**(엔진에서만) — 다른 체인이나 엔진. 그 자리에서 그 안의 노드들이 돕니다(「열기」 로 그쪽으로). 큰 단계마다 체인을 만들고, 체인을 이어 엔진을, 엔진을 이어 더 큰 엔진을 만듭니다. 서로를 부르는 고리가 생기면 저장하지 않습니다. 런에서는 다 펼쳐져 노드 하나하나가 차례로 돕니다(「펼쳐 보기」 가 그 모양).
- **화살표 칸**(화살표를 누르면) — 보통 또는 **실패하면**. 「실패하면」 은 앞 노드가 실패할 때 뒤 노드(고치는 노드)를 돌리고 앞 노드를 다시 돌립니다(최대 몇 번). 고치는 노드에는 다른 화살표를 잇지 않습니다. 보통 화살표로 고리를 만들 수는 없습니다 — 되돌아가는 길은 「실패하면」, 또는 명령 노드의 되돌리기.
- **공통 규칙**(머리줄 아래 설정 줄) — 이 체인 · 엔진의 모든 스킬 노드 지시 앞에 같이 붙는 스킬. 엔진에 두면 안에 든 체인에도 붙습니다(체인에 자기 공통 규칙이 있으면 그것).
- **작업 폴더**(설정 줄) — 런에서 Claude 가 일하고 명령이 도는 곳. **런 시작할 때 고르기**(기본) · **늘 같은 폴더** · **새 워크트리**(레포와 기준 브랜치를 적어 두면, 런 시작할 때 브랜치 이름만 넣는다 — herdr 가 워크트리와 워크스페이스를 한 번에 만들고 그 안에서 돈다. 자리는 `~/.herdr/worktrees/<레포>/<브랜치>`, 끝나도 남겨 둔다). 돌리는 맨 바깥 것(보통 엔진)의 설정만 씁니다.
- **Claude 에게 맡기기**(머리줄) — 이 체인 · 엔진을 만들거나 고쳐 달라는 글을 오른쪽 공방 Claude 입력칸에 넣습니다. 하는 일을 이어 쓰고 보내면 Claude 가 `draft.json`(초안)과 필요한 스킬을 씁니다. 캔버스 위에 「Claude 초안」 띠가 뜨면 **미리 보기** 로 보고 **적용**(초안대로 바뀝니다 — 있던 노드는 자리를 지킴) 또는 **버리기**. 단추 없이 공방 Claude 에게 「기획 파악 체인 만들어 줘」 라고 말해도 됩니다 — 하는 일이 흐리면 질문 카드로 하나씩 묻고 초안을 씁니다(폴더는 「새 체인」 · 「새 엔진」 으로 먼저 만들어 둡니다). 만드는 법(만들기 스킬)은 EDITH 레포의 `workshop/engine-skill.md` 에 있고, 공방 폴더의 `CLAUDE.md`(EDITH 가 맡아 뜰 때마다 새로 쓰는 파일 — 내 규칙은 `CLAUDE.local.md` 에)가 그 파일을 가리킵니다. 공방 Claude 만 쓰고, EDITH 를 업데이트하면 같이 바뀝니다.
- **흐름 지도**(엔진 머리줄 「흐름 지도 · 캔버스 · 펼쳐 보기」 — 엔진은 이것이 처음) — 엔진이 하는 일을 단계 칸과 줄로 봅니다. 줄 앞 아이콘은 역할(말풍선 = Claude 가 한다 · 체크 = 자동 검사 · 사람 = 사람이 확인 · 시계 = 기다림), 갈래는 칸 안 소제목. 줄을 누르면 오른쪽에 그 단계가 하는 일, **Claude 가 받는 지시**(지시 파일 앞부분 — **지시 고치기** 는 그 파일 경로를 오른쪽 공방 Claude 입력칸에 넣고, **전체 보기** 는 파일 전체, 고치면 다음 런부터), 앞 · 다음 단계와 실패하면 가는 곳, 「어떻게 연결돼 있나(고급)」(노드 → 스킬 → 지시 파일). 준비 · 측 표시 · 고치는 노드 같은 것은 숨겨 두고 **숨긴 노드 N 보기** 로 칸 아래에 이름만 봅니다. 맨 위 엔진 폴더에 `map.json` 이 있으면 칸 · 갈래 · 줄 이름 · 역할 · 설명 · 지시 파일을 그대로 따르고(형식은 EDITH 레포 `src/engineMap.ts` 머리 주석), 없으면 맨 위 노드마다 한 칸(스킬 = Claude, 명령 = 자동 검사, 설명은 SKILL.md 의 description). 초안이 있으면 초안 기준입니다.
- **펼쳐 보기**(엔진 머리줄) — 안에 든 체인 · 엔진을 노드까지 펼친 캔버스(런 화면과 같은 것). 맨 위 엔진의 큰 단계가 옆으로 서고, 그 안의 체인은 위에서 아래로 쌓이며, 체인 상자는 처음엔 접혀 있습니다(이름 · 노드 수). 상자 머리를 누르면 그 자리에서 펼치고(「모두 펼치기 · 모두 접기」 도), 노드를 누르면 그 체인으로 갑니다. 초안이 있으면 초안 기준이고, 노드 자리는 화살표 차례로 저절로 정합니다. 끌어서 옮기고 ⌘/Ctrl + 휠로 확대합니다.
- **런 전에 볼 것**(엔진 머리 아래 주황 띠, 있을 때만) — 스킬이 「없으면 멈춘다」 고 적은 작업 문서 파일(예: `bin/rules.md 를 읽고, 없으면 막힘`)을 앞 노드(화살표로 거슬러 닿는 노드 — 명령은 그 명령이 부르는 엔진 폴더 파일 · 폴더째 까는 파일 이름까지) 어디서도 만들지 않으면 알립니다. 다른 엔진에서 옮겨 온 스킬이 그 엔진의 준비 체인이 깔던 파일을 찾아 첫 노드부터 막히는 일을 런 전에 잡습니다. 경고일 뿐 적용 · 런은 막지 않고, 스크립트가 이름을 조립해 만들면 헛경고일 수 있습니다(그 스크립트에 파일 이름을 적으면 사라집니다).
- **오른쪽 공방 Claude** — 「공방 Claude 띄우기」 를 누르면 herdr 에 「공방」 워크스페이스를 만들고 공방 폴더에서 Claude 를 엽니다(처음엔 폴더를 믿는지 묻습니다). 머리줄 오른쪽 단추로 접었다 펴고, 왼쪽 가장자리를 끌어 넓이를 바꿉니다(두 번 누르면 처음 넓이, 가장자리를 고른 뒤 ← · → 키로도). 넓이는 이 브라우저에 기억합니다.
  - 스킬 노드에서 **Claude 에게 쓰게 하기** 를 누르면 그 노드 정보가 입력칸에 들어갑니다(쓰던 글이 있으면 뒤에) — 하는 일을 이어 쓰고 보냅니다. Claude 는 `skills/<이름>/SKILL.md` 만 쓰고 `engine.json` 은 고치지 않습니다(공방 폴더의 `CLAUDE.md` 안내).
  - 다 쓰면 노드 칸에 「아직 안 붙은 이 폴더 스킬」 로 뜹니다 — **연결** 을 눌러 그 노드에 붙입니다.

## 런

공방의 엔진이나 체인을 실제로 돌립니다. 런 하나가 `~/.local/share/edith/workshop-runs/<번호>/` 하나입니다. 같은 엔진을 안건마다 돌리면 런이 하나씩 쌓입니다(예: #1 기능 개발 · 출석 체크, #2 기능 개발 · 포인트 정산).

- **새 런**(왼쪽 위) — 엔진 · 체인(엔진이 위에)과 입력(모든 노드에 같이 가는 글 — 예: 기획서 링크). 작업 폴더는 공방 설정대로: 런 시작할 때 고르기면 폴더(열린 워크스페이스에서 고르거나 치면 하위 폴더 추천), 새 워크트리면 브랜치 이름, 늘 같은 폴더면 묻지 않습니다. 입력 아래 📎(또는 입력칸에 붙여넣기)로 파일을 올리면 그 경로가 입력 끝에 붙습니다. **무인 — 사람 없이 끝까지**(기본 꺼짐)를 켜면 아래 「무인 런」 대로 돕니다.
- **고르기 목록**(엔진에 있으면) — 맨 위 엔진 폴더 `actions.json` 에 `{"label", "on": "picks", "command"}` 가 있으면 새 런 칸에 그 이름의 단추가 생깁니다. 누르면 그 명령을 공방의 그 엔진 폴더에서 돌려(환경 변수 `EDITH_ENGINE` · `EDITH_WORKSHOP`, 60초까지) 표준 출력의 JSON `[{"label", "note"?, "input"}]` 을 고르기 상자로 보이고, 고르면 `input` 이 입력칸에 들어갑니다(예: 일감 목록에서 고르면 기획서 주소). 시작은 지금처럼 사람이 누릅니다.
- **대기**(보라) — 동시에 도는 런이 설정 「런」 의 한도(기본 2)에 차 있으면 새 런은 줄을 서고, 도는 런이 끝나면 먼저 온 것부터 시작합니다. 「지금 시작」 은 한도를 넘어 바로, 「줄에서 빼기」 는 멈춤으로.
- **받은 요청**(왼쪽 위, 있을 때만) — 다른 도구(대화방 봇 등)가 `~/.local/share/edith/requests/<id>.json`(`{"engine", "input", "title"?, "tag"?, "from"?, "room"?, "cwd"?, "branch"?}`) 을 두면 뜹니다. **열기** 는 새 런 칸에 그 값을 채우기만 하고(시작은 사람이 「런 시작」), 시작하면 요청에 런 번호로 답합니다. **거절** 은 답만 씁니다. 답은 `<id>.answer.json`, 요청 쪽은 그 파일이나 `edith request <id>`(읽기만 — 요청 · 런 상태 · 진행 JSON)로 봅니다. 저절로 돌지는 않습니다. 요청 파일의 `"meta"`(객체, 4KB 까지 — 요청 쪽이 런까지 넘길 것: 방 · 글 번호 등)는 EDITH 가 보지 않고, 그 요청으로 시작한 런의 작업 문서 `edith-request.json` 에 요청 전체와 함께 둡니다(노드가 요청 쪽에 알릴 때 씀). **거절** 은 사유를 받습니다(비워도 됨 — 답 파일 `reason`). 엔진(공방 것) `actions.json` 에 `{"label", "on": "request", "command"}` 가 있으면 시작 · 거절할 때 그 명령이 그 엔진 폴더에서 돌고(`EDITH_REQUEST_FILE` · `EDITH_REQUEST_STATE` started|rejected · `EDITH_REQUEST_RUN` · `EDITH_REQUEST_REASON`, 출력은 `requests/<id>.hook.log`), 요청 쪽에 알리는 일은 그 명령이 합니다. 카드에는 `tag`(예: 티켓 번호) · 접수 시각 · `title`(없으면 입력 첫 줄) · 엔진 이름 · 요청자 · 방, 입력이 노션 주소면 「노션」 단추가 보입니다.
- 시작하면 폴더를 통째로(안에 든 체인까지) 사본으로 뜨고 노드 한 줄로 펼칩니다. 공방에서 고쳐도 도는 런은 그대로입니다.
- **스킬 노드** — herdr 에 「▶ 이름 #번호」 워크스페이스를 만들고 작업 폴더에서 Claude 를 띄워, 노드마다 새 대화(`/clear`)로 공통 규칙 · 단계 지시(SKILL.md) · 작업 폴더 · 작업 문서 · 런 입력 · 결과 파일을 보냅니다. Claude 가 일을 마치고 결과 파일(`{"결과": "통과"|"건너뜀"|"실패"|"막힘", "한줄", "요약"}`)을 쓰면 다음 노드로. 「건너뜀」 은 할 일이 없어 넘어간 것(통과처럼 다음으로, 화면에서는 흐리게), 「한줄」 은 런 화면 카드에 보이는 사람용 한 줄(40자 안, 코드 · 키 · 경로 없이 — 없으면 요약 첫 문장), 「요약」 은 카드를 누르면 보입니다. 노드끼리는(체인 사이도) 작업 문서(`work/`) 파일로 넘깁니다.
- **명령 노드** — EDITH 가 직접 돌립니다. 출력은 그 노드를 누르면 보입니다.
- **갈래** — 화살표가 둘 이상으로 갈리면 갈래마다 동시에 돕니다(갈래마다 Claude pane 하나 — 본 줄 pane 옆을 나눠서, 노드끼리는 갈래 안에서 차례로). 합류 노드는 앞 갈래가 다 끝나야 돕니다. 갈래 이름은 갈라지는 자리의 노드 id(예: 맨 위 엔진의 `be` · `fe` 노드로 갈리면 `be` · `fe`). 한 갈래가 확인 필요로 멈춰도 다른 갈래는 계속 돌고, 런은 「확인 필요」 로 보입니다. 타임라인에는 갈래마다 지금 노드가 따로 뜨고, 오른쪽 런 pane 머리줄에 갈래 단추.
- **머리 단계 줄** — 런 이름 아래에 큰 단계(맨 위 엔진의 체인 · 엔진)마다 한 칸. 도는 단계(파랑) · 확인 필요(주황)는 칩에 끝난 노드 수, 끝난 단계는 ✓, 노드 반 이상을 건너뛴 단계는 줄 그어 흐리게. 이름이 모두 같은 낱말(엔진 이름)로 시작하면 그 낱말은 떼고 보입니다(마우스를 올리면 전체 이름 · 노드 수). 입력 첫 줄이 주소면 눌러 엽니다. 입력에 노션 주소가 있으면(노션 기획 · 이슈로 시작한 런) 머리줄에 노션 로고가 붙은 **노션** 단추(베이지)가 생겨 그 페이지를 새 탭으로 엽니다(주소가 여럿이면 첫 것).
- **가운데 — 타임라인**(기본, 카드 덱) — 일어난 일을 **체인(노드가 든 체인)마다 카드 하나**로 쌓습니다. 왼쪽은 시각 · 점 · 세로줄. 지금 체인(도는 노드나 확인 필요 노드가 있는 체인 — 갈래가 여럿 돌면 갈래마다)을 큰 카드로 가운데에 두고, 그 앞에 마지막으로 끝난 체인 하나, 뒤에 다음 체인 둘만 펼칩니다. 나머지는 위 「지난 체인」 · 아래 「남은 체인」 카드 묶음(덱)으로 접혀 있고, 누르면 체인마다 카드로 펼쳐집니다. 끝난 체인 카드에는 스킬 노드 수 · 걸린 시간 · 대표 결과(끝난 스킬 노드의 한 줄), 막힘 · 실패 · 사람 대기 꼬리표 — 누르면 그 체인의 줄들(노드 시도마다 카드, 통과한 명령은 「명령 N개 통과」 한 줄, 건너뛴 노드도 한 줄, 되돌림). 지금 체인 카드에는 몇 분째 · 스킬 노드 막대 · **스킬 노드 줄**(끝난 것은 걸린 시간과 한 줄, 도는 것은 Claude 설정 칩 · 몇 분째 · Claude 의 마지막 말, 확인 필요면 그 까닭). 명령 노드는 돌거나 막히거나 실패했을 때만 줄로 보이고 나머지는 「명령 노드 N개 숨김 — 보기」. 줄을 누르면 그 자리에 자세히(결과 요약 · EDITH 가 보낸 글 · 「이 노드부터 다시」). 열면 지금 체인 카드로 화면이 갑니다. 타임라인은 `events.jsonl` 에서 만들어서 이 기능 전에 돈 런은 비어 있습니다.
- **캔버스**(머리줄) — 큰 단계(맨 위 엔진에 놓인 체인 · 엔진)를 다 펼친 상자로 왼쪽에서 오른쪽으로 늘어놓습니다. 갈래는 위아래 줄로 갈렸다 합쳐지고, 엔진 상자 안은 체인마다 소제목. 노드 줄마다 상태 점 · 걸린 시간 · 결과 첫 줄, 막힘 · 사람 대기 · 몇 번째 시도는 꼬리표, 통과한 명령(`$`)은 작고 흐리게. 고치는 노드(↳)는 불린 뒤에만 보입니다. 선은 지나온 길(초록) · 지금 가는 길(흐르는 점선) · 갈 길(회색 점선). 열면 도는 상자를 가운데로 옮깁니다. 휠로 확대 · 축소(커서 자리 기준), 왼쪽 단추로 끌어 옮깁니다(노드 줄을 잡고 끌어도). 노드를 누르면 아래에 자세히.
- **오른쪽 런 pane** — 그 런의 Claude. 질문 · 승인은 여기 입력칸(질문 카드)으로 답합니다.
- **Claude 띄우기 설정** — 작업 문서에 `edith-claude.json`(`{"model", "effort": low · medium · high · xhigh · max, "mcpConfig": [절대 경로]}`, 갈래 노드는 `edith-claude.<갈래>.json` 을 먼저)이 있으면 스킬 노드를 보내기 전에 읽어, 지금 Claude 와 다르면 `/exit` 로 끄고 그 설정으로 다시 띄웁니다(노드마다 새 대화라 잃는 것이 없다). 띄울 때 쓰는 것은 이 세 칸뿐입니다 — 작업 문서는 런의 Claude 도 쓰는 곳이라 권한 인자로 스스로를 넓히지 못하게. `"why"`(왜 그 설정인지 — 예: 「판단자 deep — 확신 0.51」)는 화면에 보이기만 합니다. 노드 시도마다 실제로 띄운 설정을 남겨(`nodes/<노드>/<시도>/claude.json`) 타임라인 · 노드 자세히에 「Opus · xhigh · 판단자 …」 칩, 분석 표에 「Claude 설정 · 이유」 로 보입니다.
- **단추**(엔진에 있으면) — 맨 위 엔진 폴더의 `actions.json`(`[{"label", "command", "ask"?, "hint"?, "danger"?, "when"?}]`)이 런 머리 아래 「런 단추」 가 됩니다. 마우스를 올리면 `hint`(무엇을 하는지 — 없으면 명령), `"danger": true` 는 지우는 단추라 빨강으로 맨 끝에 떼어 둡니다. `"when": "done"` 은 런이 끝난 뒤에만 보이고 눌립니다. 누르면(ask 가 있으면 글을 받아 `$EDITH_ACTION_TEXT` 로) 명령 노드처럼 작업 폴더의 셸에서 돌고, 출력은 「최근 단추」 에. 끝 코드 0 에 `$EDITH_REWIND` 를 쓰면 되돌립니다(되돌릴 노드 중 도는 것은 끊고). `"on": "results"` 를 붙인 항목은 단추가 아니라 「결과」 화면에서 그 런의 할 일 체크가 바뀔 때마다 돕니다(`$EDITH_RESULT_TAG` · `$EDITH_RESULT_TITLE` · `$EDITH_RESULT_GROUP` · `$EDITH_RESULT_TEXT` · `$EDITH_RESULT_DONE`=1|0 — 엔진 밖 문서에 같은 체크를 옮겨 쓸 때). 기록은 단추와 같이 「최근 단추」 에.
- **레포**(엔진이 남겼으면) — 작업 문서의 `edith-repos.json`(`[{"path": "<레포 절대 경로>", "branch"?, "base"?: 기본 origin/master, "also"?: [더 볼 기준 — 예 origin/dev, 3개까지], "start"?: "<워크트리를 딴 커밋>"}]`)의 레포마다 지금 브랜치 · 커밋 안 한 파일 수 · 기준에 없는 커밋 수(0 이면 「기준에 다 들어 있음」, `also` 의 기준마다 「✓ dev 반영됨」 · 「dev 에 없는 커밋 N」) · 올렸는지를 git 으로 읽어 보입니다(읽기만 — fetch 하지 않아 원격 기준은 마지막 fetch 때). `start` 뒤 커밋이 없으면 「커밋 없음」 으로 보입니다(커밋이 없어도 기준에 없는 커밋은 0 이라 「다 들어 있음」 과 헷갈리지 않게). 레포마다 **변경 보기** — `start`(없으면 기준과 갈라진 곳)부터 지금 작업 트리까지의 diff(커밋한 것 + 안 한 것 + 추적 전 새 파일)를 보기 창에.
- **산출물**(엔진이 남겼으면) — 작업 문서의 `edith-outputs.json`(`[{"label", "path"?: "<파일 절대 경로>", "url"?: "<http(s) 주소>", "node"?: "<만든 노드 키>", "note"?}]`, 50개까지)이 레포 칸 옆 「산출물」 칩이 됩니다. 파일은 누르면 보기 창(.md 는 글로), 주소는 새 탭. 파일은 런 작업 폴더 · 실행 폴더 안의 1MB 이하 글 파일만 보입니다(링크로 밖을 가리키면 안 보임). `node` 를 적은 산출물은 그 노드 자세히에 「이 노드가 만든 것」 으로도 붙습니다.
- **요약**(끝난 런 · 엔진이 남겼으면) — 작업 문서의 `edith-summary.json`(`{"title", "did": [한 일], "chips"?: [꼬리표], "next"?: [{"label", "note"?, "action"?: "<런 단추 이름>", "done"?: true}], "check"?: [{"title", "note"?, "items": [줄]}], "outputs"?: [주요 산출물 이름]}`)이 있으면 끝난 런은 보기 단추 맨 앞 「요약」 부터 엽니다. 위에서부터 이 런이 한 일 → 이제 할 일(처음 안 끝난 단계가 「지금」 — 그 단계의 런 단추만 켜지고, 아래에 레포 상태) → 확인할 것(엔진이 사람 대신 정했거나 확인하지 못한 것) → 주요 산출물(나머지는 「모두」) → 런 단추 → 「타임라인으로」. 요약 파일이 없거나 한 일(`did`)이 비면 지금처럼 타임라인부터. 런 작업 폴더 안의 레포만 봅니다. 커밋 · 정리 · 버리기는 엔진의 런 단추가 맡습니다.
- **브라우저 화면**(머리줄, 엔진이 남겼을 때만) — 런이 띄운 브라우저(E2E 등)가 작업 문서에 `edith-live.json`(`{"port": <CDP 포트>}`)을 두면 단추가 뜨고, 누르면 그 화면을 실시간으로 봅니다. 이 기기(127.0.0.1) 포트에만 붙고, 보는 동안만 화면을 받습니다. 브라우저를 닫으면 엔진이 그 파일을 지웁니다.
- **분석**(머리줄) — 맨 위에 숫자 넷(걸린 시간 · 사람 대기 · 다시 돈 시간 · Claude 입력 토큰), **먼저 볼 것**(오래 걸린 단계 · 오래 걸린 노드와 그 노드에서 가장 긴 도구 · 사람을 기다린 구간 · 다시 돈 노드 · 병목 갈래 — 해당 없으면 「없음」, 노드 이름을 누르면 아래 단계별 시간에서 그 노드를 엽니다), **단계별 시간**(큰 단계마다 처음 시작~마지막 끝 막대, 누르면 그 안 노드의 일한 시간, 노드를 누르면 자세히). 그 아래 「자세히」 는 접어 둡니다 — **노드 표**(돈 노드마다 결과 · 시도 · 고침 · 되돌려 온 수 · 일한 시간 · 사람 대기(답 기다림 · 확인 필요) · Claude 토큰(작업 폴더의 Claude 세션 기록에서) · 모델 · Claude 설정), **엔진 기록**(엔진이 작업 문서의 `edith-records.jsonl` 에 한 줄에 JSON 하나씩 쓴 것 — 열 이름 = 키, 밀리초 시각은 시:분:초로). 시간은 `events.jsonl`(노드 상태가 바뀔 때마다)에서 — 이 기능 전에 돈 런은 비어 있습니다. 그리고 **흐름**(벽시계로 일 · 사람 대기 · 멈춤 · 빈 시간 — 갈래가 겹쳐 돈 시간은 한 번, 긴 사람 · 빈 구간과 무엇을 기다렸는지), **갈래**(갈래마다 시작 · 끝 · 일한 · 사람 시간, 먼저 끝난 갈래가 합침에서 기다린 시간 — 가장 늦게 끝난 갈래가 「병목」), **노드 안쪽**(오래 걸린 스킬 노드마다 모델 · 도구 · 질문 창 시간과 오래 걸린 도구 — Claude 대화 기록에서), **같은 엔진 런 비교**(최근 6개 런의 큰 단계마다 걸린 시간 · 전체 · 사람 대기). 「다시 돈 시간」 은 같은 노드의 두 번째 이후 시도와 고치는 노드가 일한 시간, 엔진이 `edith-records.jsonl` 에 `{"kind": "usage", "node": "<노드 키>", "codex": {"in", "out", "cacheR"}, "weekly": <주간 한도 %>}` 줄을 남기면 Codex 출력 토큰(노드마다 · 합계)과 주간 한도 % 처음 → 끝.
- **무인 런** — 새 런에서 켠 런(머리줄 「무인」). 노드가 확인 필요가 되면 사람을 기다리지 않고 새 시도로 다시 돌리고(노드마다 2번까지), 그래도 안 되면 그 노드를 건너뛰고 이어 갑니다 — 건너뛴 노드와 까닭은 런 화면 위 「무인 런이 건너뛴 노드」 와 그 노드의 자세히에. Claude 에게는 질문 창으로 묻지 말고 가정해 진행한 뒤 가정을 요약에 적으라고 보냅니다. 질문 · 권한 승인 화면(답을 기다림)은 대신 누르지 않고 그대로 기다립니다. 엔진은 `run.json` 의 `"unattended": true` · 명령 노드의 `$EDITH_UNATTENDED=1` 로 알고 자기 카드 · 질문도 같은 식으로 처리합니다.
- **알림**(macOS) — 노드가 확인 필요가 되거나 Claude 가 질문 · 승인으로 답을 기다리거나 사용량 한도에 닿으면 Mac 알림.
- **사용량 한도** — 런의 Claude 가 사용량 한도(5시간 · 주간)로 멈추면, 상태줄에서 읽은 다시 찰 시각(못 읽으면 30분 뒤)까지 기다렸다가 같은 대화에 이어 하라고 보냅니다. 기다리는 동안 머리 아래 주황 줄에 그 시각.
- **확인 필요** — 결과 파일 없이 멈춤(글로만 물었을 때 등 — 결과 없이 쉬면 한 번 일깨우고, 그래도 없으면. Claude 가 백그라운드 셸을 돌리는 동안(상태줄 「· 1 shell」)은 셸이 끝나면 스스로 이어 가니 10분 넘게 기다립니다), 「막힘」, 고치기 한도를 넘음, pane 이 사라짐, 보내는 중에 EDITH 가 꺼짐. 확실하지 않으면 다시 보내지 않고 멈춥니다 — pane 을 보고 **이어서**(그 노드를 다시 — 이번 시도 결과가 이미 있으면 그것을 받음) 또는 그 노드를 **건너뛰기**. **멈춤** 은 도는 노드에 Esc(명령은 끝냄).
- **이 노드부터 다시**(노드 상세) — 그 노드와 화살표로 뒤에 이어진 노드를 처음으로 돌려 거기서부터 다시 돕니다. 작업 문서와 지난 시도 기록은 그대로입니다. 두 번 눌러 하고, 도는 중이면(어느 갈래든) 「멈춤」 뒤에. 명령 노드가 되돌린 것까지 머리 아래 「되돌림 N번」 에 누가 · 어디로 · 왜 가 쌓입니다.
- EDITH 를 다시 켜면 돌던 런을 이어 갑니다(보내는 중이던 노드 · 명령은 「확인 필요」 로, 다른 갈래가 돌던 확인 필요 런도).

## 결과

끝난 런의 코드가 커밋에서 마지막 브랜치까지 어디 있나를 봅니다. 런마다 꺾쇠 패널, 레포마다 단계 선 — **커밋 → 올림 → 엔진이 작업 문서 `edith-repos.json` 에 정한 브랜치**(`also` — 예: `origin/dev` · `origin/stage` — 다음 `base` — 예: `origin/master`). 레포에 `"via": "<브랜치>"` 가 있으면(이슈 브랜치가 들어갈 안건 브랜치처럼 먼저 합쳐지는 곳) 「올림」 대신 「합침」 단계입니다. 그 레포에 없는 브랜치는 칸을 만들지 않습니다. 레포를 남기지 않은 런은 할 일이 있을 때만 나오고, 끝까지 다 나간 런은 맨 아래 「COMPLETE」 로 접힙니다.

- **칸** — 해시만 보면 스쿼시 · 체리픽 · 다시 만든 머지로 들어간 것을 「없다」 고 하니 앞에서부터 봅니다. 「들어감」(지금 커밋이 그 브랜치에 있다 — 언제 · 머지인지 fast-forward 인지), 「내용 일치」(해시는 달라도 딴 커밋부터의 변경을 그 브랜치에 거꾸로 적용해 보면 다 맞는다), 「n개 중 k개」(바꾼 파일 몇 개만 — 「빠진 파일」 로 목록), 「확인 필요」(같은 제목 커밋은 있는데 내용이 다르다 — 들어간 뒤 고쳐졌을 수 있다). 처음 안 끝난 칸이 빛나는 고리 — **지금 할 일** 입니다(커밋 안 한 파일이 있으면 「커밋」, 안 올렸으면 「올림」). 칸에 마우스를 올리면 근거가 뜹니다.
- **단계 단추** — 엔진 런 단추(`actions.json`)에 `"reach"` 를 적으면 그 단계가 지금 차례일 때 그 칸에 단추가 놓입니다: `"commit"` · `"push"` · `"via"` · 브랜치(`also` · `base` 와 같은 이름 — 예: `"origin/dev"`), `"clean"` 은 「COMPLETE」 줄의 정리 단추. 누르면 단추 설명 · 돌릴 명령을 보이는 확인 창을 거쳐 런 화면 단추와 똑같이 돕니다(같은 기록, 결과는 런 화면 단추 기록에서).
- 원격은 마지막 fetch 기준입니다(위 「원격 … 기준」). **새로 받기** 가 끝난 런들의 레포를 origin 에서 받습니다(같은 레포의 워크트리는 한 번). 그 밖에는 git 을 읽기만 합니다.
- 위 거르기 — 전체(끝까지 나간 런 빼고) · 할 차례 · 확인 필요 · 정리 가능(모든 레포가 마지막 브랜치까지 가고 할 일도 다 끝난 런), 찾기는 제목 · 티켓 · 브랜치 · 레포 · 「#번호」.
- **배포 할 일** — 엔진의 노드가 작업 문서에 `edith-results.json` 을 쓰면 그 런 줄에 `끝난 수/전체` 가 뜨고, 누르면 오른쪽 패널에 묶음(`group` — 예: stage · prod)마다 보입니다:

```json
[{ "tag": "출석 체크", "title": "api · 9472-confirm", "note": "마이그레이션 먼저",
   "items": [{ "text": "마이그레이션 돌리기", "done": false, "group": "stage" }, { "text": "캐시 비우기", "done": false, "group": "prod" }] }]
```

- 할 일 체크는 그 파일에 바로 적습니다. 누를 때마다 파일을 새로 읽어, 그사이 엔진이 다시 썼으면(글이 다르거나 체크가 바뀌었으면) 고치지 않고 알립니다. 런 제목은 받은 요청 · 끝난 런 요약 · 이 파일의 제목 차례로, 누르면 그 런으로 갑니다.

## 설정

- **런** — 동시에 도는 런 수(1~10, 기본 2). 넘으면 새 런은 「대기」 로 줄을 섭니다. `~/.config/edith/runs.json` 에 둡니다.
- **화면 테마** — EDITH(밝은 청록)·ULTRON(어두운 빨강). 이 브라우저에 기억합니다(다른 기기를 터널로 연 화면은 따로).
- **커밋·push 전에 묻기**(커밋 지킴이) — 켜 두면 Claude 가 `git commit`·`git push` 전에 매번 「실행 / 막기」 를 묻습니다. auto 모드여도, 허용 규칙에 넣어 둔 명령이어도. 끄면 Claude Code 의 보통 권한 확인대로. 떠 있는 세션도 다음 커밋부터 따릅니다. 다른 기기를 터널로 열었으면 그 기기의 Claude 에 적용됩니다.
- **Claude 끼리는 SendMessage 로 보내기** — 켜 두면 Claude 가 다른 Claude 세션에 herdr 로 글을 치려 할 때 막고 `SendMessage` 로 보내게 합니다. 받은 메시지는 대화 화면에 왼쪽 점선 말풍선으로 보입니다.

## 그 밖에

- **새 코드 · 다시 켜기** — 서버 코드가 바뀌면(`git pull`·고침) 머리줄에 뜹니다. 누르면 EDITH 가 같은 터미널에서 새 코드로 다시 뜨고 화면을 새로 고칩니다(herdr·pane 은 그대로). 화면만 새로 빌드됐으면 **새 화면 · 새로 고침**. 터미널에서는 `edith update`(받기·빌드·다시 켜기).
- **끌어 고르면 복사** — 화면에서 글을 끌어 고르고 손을 떼면 클립보드로 갑니다(「복사됨」). 터미널 칸도 같습니다.
- **코드 블록 복사** — 대화의 코드 블록 오른쪽 위 단추로 통째로 복사합니다. 끝 줄바꿈은 빼서 터미널에 붙여도 바로 실행되지 않습니다.
- **끝남 표시** — 끝남(초록)인 pane 을 열어 보면 herdr 에 「봤다」 로 알려 터미널 herdr 의 표시도 꺼집니다(터미널 화면의 포커스도 그 pane 으로 갑니다).
- **다른 기기에서 보기** — EDITH 는 이 기기(127.0.0.1)에서만 열립니다. 다른 기기에서는 그 기기의 EDITH 사이드 메뉴 아래에 이 기기를 적어 SSH 터널로 엽니다(README 「다른 기기의 EDITH 열기」).
